# インストールと通知の使い方

## iPhone / iPad

対応条件はiOS/iPadOS 16.4以降です。

1. Safariで公開URLを開きます。
2. 共有ボタンを押し、「ホーム画面に追加」を選びます。
3. ホーム画面に追加された「謙虚でありたい」を開きます。
4. 設定 → 「通知を受け取る」をオンにし、表示された許可を承認します。

Safariのタブで開いたままではWeb Pushを有効にできません。必ずホーム画面のアイコンから開き、アプリ内の操作をきっかけに許可してください。

## Android

1. Chromeで公開URLを開きます。
2. メニューの「アプリをインストール」またはアプリ内の「ホーム画面に追加する」を選びます。
3. インストールしたアイコンから開き、設定で通知をオンにします。

## PC

ChromeまたはEdgeのアドレスバーに表示されるインストールアイコンから追加できます。通知はブラウザとOSの両方で許可が必要です。

回答は各端末に別々に保存されます。複数端末の自動同期は行いません。移行する場合は設定画面のエクスポート・インポートを利用してください。通知にはネットワーク接続が必要です。
